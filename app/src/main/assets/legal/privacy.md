# Inkvol（页澜）隐私政策

**版本：v1 · 生效日期：2026-11-23**

Inkvol（中文别名：页澜；应用包名 `com.inkvol.app`，以下简称「本应用」）是一款本地漫画与小说阅读器，由个人开发者以开源方式发布。本政策说明本应用如何处理你的信息。

**一句话总结：本应用不收集你的任何个人信息，不设账号、不上传书库与阅读数据、不含广告与统计 SDK。只有在你自己主动配置 WebDAV 同步后，本应用才会连接你指定的服务器。**

---

## 一、我们收集哪些信息

**不收集。** 本应用没有账号体系，没有服务器，没有埋点、广告或分析 SDK，不会向开发者或任何第三方回传你的书库、阅读进度、搜索记录或设备信息。

你在使用过程中产生的下列数据，全部保存在你的设备本地（应用私有目录）：

- **书库信息**：你通过系统文件选择器授权的文件夹中的文件名、大小、页数与生成的封面；
- **阅读数据**：阅读进度、书签、划线、笔记、阅读时长统计、每本书的阅读偏好；
- **应用设置**：主题、手势、翻页动画、同步配置等；
- **崩溃日志**：应用异常退出时的堆栈信息，仅写入本机，最多保留 5 份，需要你主动导出才会离开设备。

本应用**不会**读取或收集：通讯录、短信、通话记录、精确或粗略位置、相册全量内容、设备识别码（IMEI / Android ID / 广告 ID）、已安装应用列表。

## 二、权限说明

本应用的安装包声明了以下权限，用途逐条说明：

| 权限 | 用途 |
|---|---|
| 无存储权限 | 导入与读取书籍全部通过系统 Storage Access Framework（SAF）完成，只访问你显式授权的文件夹或文件 |
| `INTERNET`、`ACCESS_NETWORK_STATE` | **仅**用于你主动开启的 WebDAV 同步；默认关闭，未配置服务器时不会产生任何网络请求 |
| `WAKE_LOCK`、`RECEIVE_BOOT_COMPLETED`、`FOREGROUND_SERVICE` | 由系统 WorkManager 库声明，用于在你离开应用后继续完成你发起的书库扫描任务并在重启后恢复调度；本应用不常驻前台服务 |

「应用锁」（可选，默认关闭）使用系统锁屏凭据（密码 / 图案 / 指纹）：验证由 Android 系统完成，本应用无法读取、也不会存储或上传任何生物特征数据。未设置锁屏密码的设备上该功能不会生效。

## 三、网络与第三方

- **默认零联网**：不配置同步时，本应用不会发起任何网络请求。
- **WebDAV 同步（可选）**：仅当你主动填写服务器地址、账号与应用密码并开启同步后，本应用才会连接**你指定的那台服务器**。传输内容为阅读进度、书签、划线笔记、每本书偏好、设备名称，以及（按设置）单文件导入的书籍文件；同步目录、服务器与账号均由你决定。应用密码使用 Android Keystore 加密后保存在本机。
- **第三方服务**：WebDAV 服务提供商（例如坚果云）对你上传的数据有其自身的隐私政策，本应用无法控制该服务器上的数据。
- **无第三方 SDK 上报**：图片加载、压缩解压、压缩归档等依赖均在本机运行，不包含广告、统计或崩溃上报 SDK。

## 四、系统备份

本应用允许 Android 系统的自动备份（`allowBackup`）。在开启系统云备份的设备上，系统可能把你设备中的应用数据库（书库索引、阅读进度、书签、笔记）与设置备份到你的 Google 账号或设备厂商的云服务。

- **开发者无法访问这些备份**，备份的传输与保存由操作系统与你的云服务商完成；
- 封面、EPUB 提取图片、TXT 解析缓存与崩溃日志**不参与**云备份；
- 你可以在系统「设置 → 备份」中关闭对本应用的备份，或整体关闭系统云备份；
- 书籍源文件不在备份范围内：本应用只保存你在 SAF 中授权的引用，不复制你的文件。

你也可以随时在应用内「设置 → 存储与备份」导出 JSON 备份文件，该文件的去向完全由你决定。

## 五、数据的保存与删除

- 卸载本应用会删除应用私有目录中的书库索引、阅读进度、设置与缓存；你通过 SAF 授权的原始书籍文件**不会被删除**。
- 应用内删除书籍可选择「仅从书架移除」或「连文件删除」；后者只会删除你在本应用中授权过的那个文件。
- 若开启了 WebDAV 同步，删除会按同步规则在其它设备上传播；你可以随时在设置中停用同步或清除同步配置。

## 六、儿童

本应用不面向 13 岁以下儿童，也不收集任何个人信息。应用展示的内容完全来自你自行导入的文件，内容适宜性由你自行判断。

## 七、你的权利

由于本应用不在服务器上保存你的任何数据，你对自己数据的控制是完整的：随时查看、导出、删除，或卸载应用以清除全部本地数据。若你对本政策有疑问，可通过下方方式联系。

## 八、政策更新
