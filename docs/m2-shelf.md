## 1. 已交付

### 数据层（DB v2）

- `categories` + `book_categories`：全局书夹，多对多；
- `progress` + `page_bookmarks`：为 M3 预留，M2 只读 `percent`；
- `books.read_status`：未读/在读/读完（默认 UNREAD）；
- 书架查询统一过滤 `libraries.hidden = 1`（隐藏书库默认排除）；
- 删除书夹只删关系，不删书；重复加入幂等；`moveCategory` 交换 sort_key。

### 书架三视图

| 视图 | 能力 |
|---|---|
| **书夹**（默认） | 智能书夹横滑行（未读/在读/读完/有书签/未分类）+ 我的书夹 2×2 封面拼贴卡 + 数量 + 新建卡；长按编辑（改名/换色/删除/前移/后移） |
| **系列** | 按 `series` 聚合，封面拼贴 + 卷数，点击进入系列页 |
| **平铺** | 单本网格，长按多选，底部操作条「加入书夹」 |

- 视图选择写入 DataStore `library_view`，**切换即持久化，冷启动不重置**（已实测重启后保持「平铺」，切回「书夹」再重启仍保持）；
- 设置页「默认视图」「加号默认动作」两行可循环切换，与书架共用同一键。

### 书夹页

- 返回、标题、数量、多选态；
- 用户书夹：多选「移出书夹 / 移到…」；
- 系统书夹：多选「加入书夹」；
- 空书夹提示「从书架长按移入」。

### 导入

- 书架右上 44dp 圆形加号（扫描中转圈）；
- 单击按设置执行：询问（默认三选一菜单）/ 文件夹 / 文件 / 重新扫描；
- 长按加号始终弹菜单；
- 三入口：导入文件夹（SAF 目录）、导入文件（SAF 单文件，引用式）、重新扫描（遍历全部 folders）；
- 单文件导入：持久 URI + cache 临时副本探测 + 封面，归入「单文件导入」虚拟库的「未分类」。

### 覆盖层

- 菜单/编辑器/书夹选择面板均为页内覆盖层；
- 新增 `LocalPageOverlayController`：覆盖层激活时宿主隐藏底栏与侧栏，遮罩不再被 chrome 压住；
- 底部面板 `navigationBarsPadding`。
