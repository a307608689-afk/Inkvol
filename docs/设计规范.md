# Inkvol 设计规范

> 单条累积制：每条规范 = 条款 + 原因 + 合规写法示例 + 违例模式。新规范追加编号，不改旧条。

## §1 点击反馈几何一致性（2026-11-22）

**条款**：所有可点击组件的点击反馈（ripple 波纹、按压高亮/阴影）必须与组件自身的几何形状一致——玻璃画了什么形状，反馈就是什么形状。

**原因**：Material3 的 ripple 默认按组件的**矩形 bounds** 展开；玻璃组件（`GlassRounded`）的形状只在绘制层生效，不会自动裁剪波纹。圆形玻璃钮配矩形波纹，按压瞬间会出现方形阴影（实测：手机书架标题行排序钮）。

**合规写法**：`clip(shape)` 必须挂在 `clickable / combinedClickable` **之前**：

```kotlin
Modifier
    .size(44.dp)
    .clip(CircleShape)      // 先裁形状
    .clickable { ... }      // 波纹被裁成圆形
```

（书架标题行加号钮即为既有合规样例：`.clip(CircleShape).background(primary).combinedClickable(...)`。）

**违例模式**：`clickable` 挂在未裁剪的组件上，而视觉形状（玻璃/背景）由内部绘制提供 → 方形波纹穿帮。

**两种合规路线**：
1. 有波纹：`clip(shape)` 在 `clickable` 之前（形状裁剪）；
2. 无波纹：`clickable(interactionSource, indication = null)` + 按压缩放动画（`graphicsLayer`/`layerBlock`）——形状天然无关，侧栏 `RailFab`、导航项 `GlassRailItem`、底栏胶囊均为该模式。

**存量排查结论（2026-11-22）**：
- 手机书架标题行排序钮：违例（`clickable` 无 clip）→ **已修**（加 `clip(CircleShape)`）；
- 侧栏 `RailFab` / `GlassRailItem` / 底栏胶囊：`indication = null` + 按压缩放 → 天然合规，无需改动；
- 加号钮（primary 实底）：`clip(CircleShape)` 先行 → 合规样例。

**新增可点击组件时的自检**：视觉形状是圆/胶囊还是矩形？反馈走波纹还是按压缩放？走波纹 → 必须先 clip；走按压缩放 → indication 必须显式置 null。
